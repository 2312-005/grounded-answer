# AI Usage
I used ChatGPT during the development of this project as a coding and development assistant.

- Used ChatGPT to help build the initial project structure and code.
- Used it to develop and update the RAG retrieval and evidence-handling parts.
- Used it for debugging errors and fixing issues during development.
- Used it to create and improve test cases.
- Used it to check retrieval results and improve unsupported-question handling.
- Used it to improve the frontend.

I tested and modified the generated code myself and verified the final system with the project test cases.
